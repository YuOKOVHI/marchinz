# 大会動画リスト作成AIへの必須指示

## 日付は「配信元の公開日」を正として必ず入れる

大会動画リストの `配信日` は、演技日・大会開催日・撮影日ではありません。
**YouTube等の動画配信元がその動画を公開した日**です。大会動画ページの既定の並び順と「年で絞り込み」は、この値を基準にします。

### 1行ごとの確認手順

1. 追加・修正する動画の `URL` を開く。
2. 配信元ページの公開日を確認する。YouTubeでは動画ページの公開日、または `yt-dlp` の `upload_date` を使う。
3. `配信日` に **`YYYY-MM-DD`**（西暦・月日ゼロ埋め）で記入する。
4. URLと公開日が一致していることを確認してからCSVを保存する。

例: `2026-08-10`

### 禁止事項

- 大会開催日、演技日、動画タイトル中の年だけから `配信日` を埋めない。
- `2026/8/10`、`2026年8月10日`、時刻付きなどの形式を入れない。
- 公開日を確認できないまま推測で日付を入れない。
- `data.json` / `data.inline.js` を直接編集しない。

公開日を確認できない動画は、CSVの `配信日` を空欄のままにし、対象URLと未確認理由を作業報告に残してください。空欄を0日や仮の日付で埋めることは禁止です。

## 正本と反映手順

1. `sync_csv_to_json.py` の `SOURCE_CSVS` に含まれる該当CSVを編集する。CSVが唯一の正本です。
2. `python3 sync_csv_to_json.py` を実行し、`data.json` と `data.inline.js` を再生成する。
3. `python3 check_data.py` を実行して、全CSVと派生データの件数・列を検証する。
4. 日付未入力が残る場合は、件数とURLを報告する。確認済みの公開日を後から追記して、同じ反映手順を実行する。

## AIへの短い依頼文

> 大会動画CSVを更新してください。各行の `配信日` は、動画配信元の公開日を `YYYY-MM-DD` で必須記入してください。大会日・撮影日・タイトル年からの推測は禁止です。公開日が確認できない場合は空欄にしてURLと理由を報告してください。CSVだけを編集し、最後に `python3 sync_csv_to_json.py` と `python3 check_data.py` を実行してください。`data.json` / `data.inline.js` は直接編集しないでください。
