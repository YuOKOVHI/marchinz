# MarchinZ ユーザー向け機能一覧

開発・運営向けの **画面・データ・セキュリティの仕様一覧**は **`docs/MARCHINZ_SPEC.md`** を参照してください。

## マーチンズ/MarchinZで、できること。

- ショウ動画を、団体名・大会名・フリーワードで検索できます。
- 検索結果はカード表示で見やすく、シェアもかんたんです。
- メディアページで、雑誌・マンガ・アニメ情報をまとめて確認できます。
- クリエイター向けのおすすめサービス情報を確認できます。
- 運営ページで公式情報（Xなど）を確認できます。

## MLL（Marching Life Log）

- **公開に設定され、かつ投稿者がプロフィールの MLL タブを公開にしているログ**は、ログインしなくても TOP の一覧に表示されます。
- Googleログインで、あなた専用のMLLを使えます。
- 大会名・開催日・参加区分・会場・メモを記録できます。
- チケットページURL・公式ページURLも登録できます。
- 開催日前後で参加区分の表示が自動で自然な文言に切り替わります。
- 将来開催の大会・演奏会情報を一覧で見られます。
- 情報作成者や参戦予定ユーザーをタップしてプロフィールを確認できます。
