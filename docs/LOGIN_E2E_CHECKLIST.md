# MarchinZ Login E2E Checklist

最終更新: 2026-05-06

## リリース前チェック（5分版）

- [ ] `#top` 遷移（ロゴ/TOPリンク）が正常
- [ ] `#login` / `#signup` に遷移できる
- [ ] 投稿・保存・いいね等の要ログイン操作でガードされる
- [ ] `#admin` 直アクセス時に一般ユーザーは `#top` 側へ戻る
- [ ] スマホ: ドロワーのページ選択で即閉じ
- [ ] スマホ: フッター3画像が1行表示
- [ ] 大会動画: `MIX3` 注意文は `MIX3` タブ時のみ表示
- [ ] 大会動画: 初期並び（無検索時）が仕様どおり
- [ ] フッター版番が更新済み

## 詳細版（20分版）

### 1) 未ログイン

- [ ] `#login` / `#signup` に遷移できる
- [ ] 投稿・保存・いいね等の要ログイン操作でガードされる
- [ ] `#admin` または `#admin/reports` に直接アクセスしても表示されず `#top` 側へ戻る
- [ ] ゲストUI（ヘッダー/ドロワー）が正しく表示される

### 2) 一般ログイン

- [ ] Googleログイン成功後、元ページへ戻る（`return_to`）
- [ ] プロフィール編集・設定ダイアログが開ける
- [ ] 自分のデータのみ作成/更新/削除できる（他人データは不可）
- [ ] ログアウト後にユーザー専用UIが消える
- [ ] withdrawnユーザーでない限り通常機能が使える

### 3) 管理者ログイン

- [ ] **「管理」**ナビが表示され、`#admin/reports` に遷移できる
- [ ] 管理者専用操作（通報管理等）が使える
- [ ] 一般ユーザーとしての操作も破綻しない
- [ ] ログアウト後、管理者UIが即時で消える

### 4) 回帰チェック（詳細）

- [ ] `#top` 遷移（ロゴ/TOPリンク）が正常
- [ ] スマホ: ドロワーのページ選択で即閉じ
- [ ] スマホ: フッター3画像が1行表示
- [ ] 大会動画: `MIX3`注意文は `MIX3` タブ時のみ表示
- [ ] 大会動画: 初期並び（無検索時）が仕様どおり
- [ ] フッター版番が更新済み

## 実行メモ

- 本番反映は以下を実行:
  - `netlify deploy --prod --dir .`
- 反映後は本番URLとユニークデプロイURLを記録する。
