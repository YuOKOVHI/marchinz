# MarchinZ ユーザー向け文言ガイド

最終更新: 2026-05-06

## 目的

ユーザー向けメッセージ（`alert` / 画面内エラー表示）を、短く・丁寧に・行動しやすく統一する。

## 基本方針

- 1文目で事象を端的に伝える
- 2文目で次アクションを示す
- 敬体（です・ます）で統一する
- 原因の断定は避ける（ネットワーク等）

## 推奨テンプレート

- **通信系**
  - `通信エラーが発生しました。通信環境をご確認ください。`
- **権限系**
  - `この操作を行う権限がありません。`
- **混雑・一時失敗**
  - `ただいま混み合っています。少し時間をおいて再度お試しください。`
- **保存・更新失敗（汎用）**
  - `保存に失敗しました。時間をおいて再度お試しください。`

## NG例

- 技術詳細の露出（例: 生のエラー文字列をそのまま表示）
- 口調の混在（です・ます と 命令調の混在）
- 長すぎる文（改行を含む説明過多）

## 運用ルール

- 新規メッセージは `*_MESSAGE` 定数に追加して再利用する
- 可能な限り `*FriendlyErrorMessage()` を経由して表示する
- 画面内メッセージと `alert` のトーンを一致させる

## 対象ファイル（現時点）

- `auth.js`
- `community.js`
- `mll.js`
